# Tuttle__Learning_Japanese_Kanji
## "The innovative method for learning the 520 most essential Japanese kanji characters."

This project is originally inspired by the book: "Tuttle, Learning Japanese Kanji" by Glen Nolan Grant (ISBN 978-4-8053-1168-4).

The pdf file contained located at tuttle_kanji/tuttle.pdf is not meant to be an exact replica of the book mentioned above.
My contribution to this project is in providing the reader complete mnemonics for the kunyomi and onyomi readings, as well as the Kanji compositions.

Note that for each Kanji entry, the corresponding stroke-order for the kanji is also presented.

Beautiful typesetting and layout thanks to tikz & latex makes this document also visually appealing.
